## 1. Fair agent scheduler

- [x] 1.1 Add `runtime/workflow_scheduler.rs`: `WorkflowScheduler { capacity, runs: BTreeMap<run_id, RunQueue>, tick }` with `enqueue(run_id, share) -> Waiter`, an RAII `Slot`, `suspend` and `unsuspend`, `remove(run_id)`, `set_share` and `snapshot(run_id) -> {queued, running}`.
